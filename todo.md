# Schwesterherz UI/UX Upgrade Roadmap

Planned boutique-spa UI/UX additions to elevate **Schwesterherz** into a bespoke luxury studio experience:

- [x] **1. Editorial Typography & "Quiet Luxury" Aesthetics** *(Completed — see `done.md`)*
  - Pair **Cormorant Garamond** (editorial serif display font) with **Plus Jakarta Sans** for clean body copy and pricing.
  - Add warm tonal surfaces, multi-layered soft depth shadows, and generous whitespace across sections.

- [ ] **2. Interactive "Before & After" Comparison Slider**
  - Upgrade the **Gallery** page Before/After showcase into a smooth, draggable split-screen comparison slider supporting mouse, touch, and keyboard navigation so visitors can inspect treatment results interactively.

- [ ] **3. "Find Your Ritual" Interactive Treatment Matcher**
  - Build a compact 2–3 step interactive consultation guide (*"What does your body need today?"* → *Deep Relaxation / Foot Health / Facial Glow* → *Available Time*) that recommends the ideal package and opens a pre-filled WhatsApp or booking link in one click.

- [ ] **4. Sensory "Treatment Journey" Timeline**
  - Add a guided visual step-by-step experience (*1. Arrive & Tea → 2. Scalp/Skin Analysis → 3. Deep Immersion → 4. Afterglow*) with subtle scroll-triggered reveals for signature treatments like the **Shazay Head Spa Ritual**.

- [x] **5. Digital Gift Voucher ("Gutschein") Configurator with Live Preview** *(Completed — see `done.md`)*
  - Interactive live voucher card preview in the Schwesterherz brand palette with treatment/amount selection, personal dedication, pickup vs. digital delivery options, and one-click WhatsApp/email inquiry.

- [ ] **6. Asymmetric Editorial Bento Grid for Studio Atmosphere**
  - Replace uniform 3-column image grids with an asymmetric Bento layout mixing vertical founder portraits, macro spa textures, an ambient brand quote, and studio interiors to accommodate both portrait and landscape photography naturally.

- [ ] **7. Sticky Mobile Action Bar & Seamless Page Transitions**
  - Add a safe-area-padded sticky mobile bottom bar (`[Call] · [WhatsApp] · [Book Now]`) after scrolling past the hero, paired with native `View Transitions API` route transitions and tactile hover/press micro-interactions.
